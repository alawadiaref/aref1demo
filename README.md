# عارف العوادي — السيرة الذاتية | Aref ALawadi — CV

موقع شخصي لعرض سيرتي الذاتية، بنفس ألوان وأسلوب موقعي الأول (التركوازي + العنابي، وعناوين بلونين، ورسومات Alawadi Studio).

## المميزات
- ترمنال تفاعلي «جرّبني»: الزائر يكتب أوامر (help, about, skills, journey, projects, contact, hire, theme…) أو يضغط اقتراحات، وبالعربي كمان (مهارات، تواصل…)
- كروت تميل ثلاثي الأبعاد مع ضوء يتبع الماوس، أزرار مغناطيسية مع موجة عند الضغط، مؤشر ماوس متوهج، حركة للواجهة مع الماوس، وخط زمني يمتلئ مع التمرير
- انترو تفاعلي فخم: رسم شعار Alawadi Studio، جزيئات تتفاعل مع الماوس واللمس، شريط تحميل، وخروج بلوحين مائلين مثل الشعار (يظهر مرة في كل جلسة، وفيه زر تخطي)
- عربي 🇸🇦 / English — زر تبديل اللغة (الإعداد يُحفظ في المتصفح)
- وضع ليلي / نهاري
- متجاوب مع الجوال والتابلت والكمبيوتر
- حركات عند التمرير، تأثير كتابة للمسمى، عدادات، شريط تقدم
- مسيرتي (الخبرة + التعليم) على شكل خط زمني
- المهارات، اللغات، الأعمال القادمة
- تواصل: بريد، جوال، واتساب، نسخ البريد، ونموذج رسالة
- زر تحميل السيرة الذاتية PDF

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | محتوى الموقع (النصوص العربية) |
| `script.js` | تفاعلات الموقع والمسميات المتحركة `ROLES` |
| `styles.css` | التصميم — الألوان في أعلى الملف `:root` |
| `admin.html` / `admin.js` / `admin.css` | لوحة التحكم المخفية |
| `data/content.json` | التعديلات المحفوظة من لوحة التحكم |
| `i18n-en.js` | النصوص الإنجليزية الافتراضية |
| `intro.css` / `intro.js` | الانترو |
| `interact.css` / `interact.js` | الترمنال والتأثيرات التفاعلية |
| `assets/` | الشعار، الرسومات، صور المشاريع، وملف السيرة الذاتية |

## التعديل
- لتغيير نص: عدّله في `index.html` (عربي) وفي `i18n-en.js` بنفس المفتاح `data-i18n`.
- لإضافة مشروع: انسخ عنصر `<li class="work">` في قسم الأعمال وضع رابطه وصورته.
- لتحديث السيرة: استبدل `assets/Aref-Alawadi-CV.pdf`.

## لوحة التحكم المخفية 🔐
- الرابط: `admin.html` (غير موجود في القائمة)، أو اضغط على الشعار **ضغطتين سريعتين ثم ضغطة ثالثة مطوّلة** (يظهر وميض خفيف ثم تفتح صفحة الدخول).
- كلمة المرور غير مكتوبة في الكود؛ المخزّن فقط بصمة PBKDF2 (150,000 تكرار).
- تقدر تعدّل منها: كل النصوص (عربي + English)، المسميات المتحركة، بيانات التواصل، روابط المشاريع وحالتها، ونِسب المهارات.
- **معاينة**: تعرض التعديلات في تبويب جديد قبل النشر.
- **حفظ ونشر**: يكتب `data/content.json` في المستودع عبر GitHub API. يحتاج Fine-grained token بصلاحية
  *Contents: Read and write* على هذا المستودع فقط (يُدخل مرة من تبويب «النشر والإعدادات»).

> ⚠️ لأن الموقع ثابت بدون سيرفر، تسجيل الدخول يحمي الواجهة فقط. الحماية الفعلية للتعديل هي التوكن — لا تشاركه مع أحد.
